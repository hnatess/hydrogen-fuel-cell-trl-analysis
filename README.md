# Hydrogen Fuel-Cell Aviation Power Systems – Concept Design & TRL Analysis (TÜBİTAK 2209-A)

This repository contains my TÜBİTAK 2209-A research proposal on a hydrogen fuel-cell electric aviation power system concept and a Technology Readiness Level (TRL) roadmap, framed as an alternative to turboshaft-based architectures for rotorcraft.

## Project focus
- Conceptual architecture: **H2 storage → PEM fuel cell stack → power electronics → PMSM motor(s)**
- Mission-phase modeling (hover / climb / cruise) with control logic
- Thermal management as a key bottleneck (cooling loop concept)
- Comparison perspective against **Brayton/turboshaft** efficiency trends
- TRL assessment & roadmap for 2030–2040 (key subsystems: high-pressure tanks, MW-class PEMFC, motors)
